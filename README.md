# 故人

> 从你和某个人的聊天记录里，把 TA 的样子留下来，然后用 TA 的方式跟你说话。

**不是做一个"更懂你的助手"，是做一个会敷衍你、会记错事、深夜才回、偶尔已读不回的 TA。**

所有数据只存在你自己的设备上。模型用你自己提供的 API Key，本项目不托管模型、不代购 Key、不存 Key。

---

## 它跟别的 AI 陪伴有什么不同

| | 常见 AI 陪伴 | 故人 |
|---|---|---|
| 人设来源 | 手写提示词 | 从真实聊天记录蒸馏 |
| 记忆 | 有 | 有，且分三层 |
| 缺点 | 没有，永远耐心友善 | 有，且强度可调 |
| 回复速度 | 秒回 | 有作息，深夜不在线，会已读不回 |
| 主动找你 | 不会 | 会 |
| 身份 | 明确是 AI | 界面显著标注 AI 生成 |

## 下载安装

到 **Releases** 页面下载：

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `故人-Windows-v0.1.0.zip` | 解压后双击 `故人.exe`。后端已内置，**不用装 Python 或任何环境** |
| Android | `故人-Android-v0.1.0.apk` | 装完即用。后端已内置在 App 里，**不用连电脑、不用配地址** |

第一次打开后在「设置」里填你的 LLM API Key（DeepSeek / 通义千问 / OpenAI，或任何 OpenAI 兼容接口的地址和模型名），就可以开始。

> 手机端没有截图 OCR（识别模型太大，没塞进 App）。想从聊天记录蒸馏，请用「粘贴文本」导入，详见 [使用说明.txt](使用说明.txt)。

## 怎么创建一位

三种方式，都在人物列表右下角的「＋」里：

**1. 蒸馏（最像）**
导入聊天记录 → 模型从中提炼人格 → 逐条人工校准。

- 电脑版支持**截图 OCR**：微信/QQ 聊天长截图直接丢进去，离线识别（内置 PP-OCRv3 中文模型），滚动重叠会自动去重。
- 也可以粘贴导出的聊天记录文本。
- 提炼出的每条特质都挂着**原文证据**，对不上就说明是模型编的 —— 校准页逐条勾选，删掉不准的。

**2. 性格标签**
没有聊天记录时，勾选任意几个标签（高冷 / 温柔 / 毒舌 / 元气 / 成熟 / 文艺 / 幽默 / 内向），填个名字，凭空造一个。

**3. 手动**
自己填基本信息、说话风格、知道什么不知道什么。

## 它会像真人的几个地方

- **作息**：按你设定的在线时段行动，深夜不回消息。
- **回复延迟**：不是秒回，而是过一会儿才回。延迟有随机性，不是固定值。
- **已读不回**：按概率发生。你等不到回复，不是 bug。
- **主动发起**：会记得上文聊过的事，隔一阵突然来一句。
- **缺点**：会敷衍、会记错、会自我开脱。强度可调 —— 调到 0 就是个有耐心的 AI，调到高就是真人也受不了的那种人。

## 三层记忆

混在一个桶里，AI 会把自己知道的事当成你也知道 —— 这是大多数聊天机器人的通病。所以分三层存：

- `self`：TA 自己的近况、习惯、观点
- `user`：TA 眼里的你
- `shared`：你们之间的约定和共同经历

每个角色的记忆和聊天记录彼此独立，退出重进不丢。

## 自定义后端

App 自带后端，开箱即用。也可以把后端单独跑起来，用网页版客户端：

```bash
docker compose up -d --build
# 浏览器打开 http://<这台机器的IP>:8000/app
```

或者不用 Docker：

```bash
pip install -r requirements-docker.txt
cd server
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Windows 下可直接双击 `run-server.bat`。

- Key 在网页右上角「设置」里填，只存你浏览器本机。
- 数据（人格档案 / 记忆 / 收件箱）都在 `./server/data`，删容器不丢。

## 从源码构建

需要 Flutter 3.47+，打 APK 还需要 JDK 21。

```bash
cd flutter_app
flutter pub get

flutter build windows --release   # 产物在 build/windows/x64/runner/Release/
flutter build apk --release       # 产物在 build/app/outputs/flutter-apk/
```

Windows 版如果要带 Python 后端（含截图 OCR），把 `server/` 用 PyInstaller 打成单文件 exe，放到 exe 同级的 `server/` 目录下：

```bash
cd server
pyinstaller --onefile --windowed --name guren-server main.py
```

不打包后端也能跑：App 起不来外部后端时会自动回退到内置的 Dart 后端，只是没有 OCR。

## 三条不可协商的红线

写死在代码里，**不在配置里、没有接口能改**：

1. 不人身攻击、不辱骂
2. 不泄露真实人物隐私
3. 不引导自我伤害或违法违规
4. 不冒充真人欺骗第三方；被问起必须如实说明是 AI 模拟

提示词能被绕过，所以输出层还有一道硬校验。

## 合规与伦理

用真实的人的聊天记录做人格，涉及个人信息处理：

- **必须获得对方知情同意**。蒸馏前会要求你显式勾选确认。
- **必须显著标识 AI 身份**，不得让人误以为是真人。
- 所有数据留在你自己的设备上，除你主动触发的模型调用外不上传任何服务器。
- 本项目不附带任何真实个人信息或聊天记录。

仅供学习研究，请勿用于冒充他人或误导第三方。
