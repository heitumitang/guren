故人 · 使用说明
================

一个让你和“想留住的TA”继续聊天的本地小应用。所有数据只存在你自己设备上

两个版本
--------
- 电脑版（本 zip）：双击“故人.exe”即用，内置 Python 后端，带截图 OCR
- 手机版（guren-Android-v0.1.0.apk）：装完即用，**后端已内置在 App 里**，
  不用连电脑、不用配地址、不用装任何东西。填好 API Key 就能聊

手机版与电脑版的三点差异
----------------------
- 手机端没有截图 OCR（识别模型太大，没塞进 App）
  想从聊天记录蒸馏，请用“粘贴文本”导入：在微信/QQ 里导出聊天记录为 txt，复制进去即可
  蒸馏向导里 OCR 那个选项在手机上点了没有反应（正在研究怎么解决）
- 手机端设置页不显示“后端地址”一栏——因为后端就在 App 里
  如果那一行显示“内置后端未启动”，点旁边的“重试”即可，通常是权限或内存紧张
- 数据位置不同：手机存在 App 私有目录的 guren-data\ 下（卸载会一起清掉，
  换手机前建议在电脑版里备份，或用系统的应用数据备份）；电脑版就在 exe 同级目录

快速开始（电脑版）
----------------
1. 解压本 zip 到任意目录（路径里有中文没关系）
2. 双击“故人.exe”。第一次打开会自动启动内置后端（无需安装 Python 或任何环境），
   稍等一两秒即进入人物列表
3. 点右上角“设置”（齿轮图标）：
   - 填你的API Key（支持 DeepSeek / 通义千问 / OpenAI，也可填任何
     OpenAI 兼容接口的地址和模型名）
   - 顺带填一下你自己的资料（名字等），TA 聊天时会知道你是谁
4. 回到列表，点右下角“+”，三种方式创建一位：
   - 蒸馏：导入微信/QQ 聊天截图（OCR 自动识别，已内置），
     或粘贴导出的聊天记录文本，让模型从中提炼人格；
   - 手动：自己搭一个；
   - 预设：高冷/温柔/毒舌等标签自由组合
5. 点头像开始聊。TA 会按作息时间在线、偶尔主动找你，像真人一样

说明
----
- 数据位置：本目录下的 guren-data\ 文件夹（人物、记忆、聊天记录都在里面）
  换电脑/重装前，把 guren-data\ 拷走即可带走全部内容
- API Key 只保存在你自己电脑的设置里，每次请求直接带给模型服务商，
  本应用不托管、不上传
- 所有回复由 AI 模型生成，不是真人；请勿用于冒充他人
- OCR 截图识别已内置（RapidOCR，PP-OCRv3 中文模型，离线可用）：
  一次识别约几秒到十几秒，取决于截图长度；截图越长切块越多
  识别后可在蒸馏向导里预览、删改消息再蒸馏
- 想彻底退出：直接关窗口即可，内置后端会随之退出，不会残留进程
